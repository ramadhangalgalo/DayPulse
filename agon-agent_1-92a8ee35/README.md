# DayPulse 🚀

A daily productivity tracker to log activities, celebrate achievements, and review your day.

## Features
- 📅 Daily activity timeline
- 🏆 Achievement vault
- 🔥 Streak tracking
- 📊 Analytics & insights
- 🌙 Dark/Light mode
- ⏱️ Focus timer

## Tech Stack
- React + TypeScript
- Vite
- Tailwind CSS
